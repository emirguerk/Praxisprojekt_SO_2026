Edit Table

Edit the chart data directly in the table:

Any changes made to the table are immediately reflected in the chart preview.

  • Editing captions updates the corresponding labels in the chart legend.
  • Editing numeric values updates the chart data.
  • Adding or removing rows and columns changes the displayed data depending on the selected chart type.

Chart type behavior

Bar Chart

  • All rows and columns in the table are included in the chart.
  • Each row represents a data series, and each column represents a category.

Line Chart

  • All rows and columns in the table are included.
  • Changes to any values are immediately reflected in the line chart.

Donut Chart

  • Only the first two rows of the table are used.
  • The first row defines the labels.
  • The second row defines the values.
  • The chart currently displays values as percentages.
Edit Chart

Customize the appearance of your chart.

  • Add or edit a chart title.
  • Add or edit a chart description.
  • Configure chart options depending on the selected chart type.

Chart Type Options

Bar Chart

  • Choose between a vertical or horizontal layout.

Line Chart

  • Select the line style: Straight, Smooth, or Stepline.

Donut Chart

  • Choose whether to display the total value in the center of the chart.
