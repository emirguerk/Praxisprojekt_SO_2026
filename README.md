# Praxisprojekt_SO_2026

## Microsoft Marketplace

**Title:** MyCustomCharts

**Summary:** This project is developing a Microsoft Word add-in that allows users to create, insert, and manage charts directly within Word Online. The add-in extends Word's existing functionality to edit charts without switching to external applications.

**Description:** The goal of this project is to develop a simple prototype of an add-in for Word Online that allows users to create and insert charts from their data directly in Word Online without having to go through Excel Online. In this project, a **simple prototype** refers to a minimal version of the add-in that provides only the core functions. This includes a simple workflow that enables users to create and edit charts. The prototype should be functional with minimal effort, as the focus is not on developing a complete end product. For this reason, the prototype will not be published on the Microsoft Marketplace, but it does relates to the official Microsoft guidelines for Office add-ins.

**Functionality:** Users can create new charts and update existing ones. To ensure the document always reflects the latest data and visualizations, you can synchronize it. When creating or updating a chart, various chart types are available: <ul><li>**Bar charts** for displaying and comparing values across different categories. </li><li>**Line charts** for displaying trends and changes over a period of time.</li><li>**Donut charts** for displaying proportions and distributions.</li></ul>

**Office Add-in Requierements:** The prototype is using office.js and a valid manifest depending on Office add-ins Manifest Guidelines

**Security:** No user data will be stored outside the Microsoft Word Online environment. Every data is stored as xml in the word online document.

**Privacy Policy:** The prototype does not provides any login process or saving personal user data. Here no sensitive or personal data will be published.
